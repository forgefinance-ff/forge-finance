# Forge Finance: pacote de lançamento

Thiago, este pacote traz os planos novos, a preparação para o lançamento e a aba de custos no `/admin`.

## Como usar
1. Descompacte este zip em uma pasta.
2. Abra essa pasta no Claude Code.
3. Cole a mensagem abaixo:

```text
Leia docs/PUBLICAR-PRODUCAO.md e siga o roteiro desde a Etapa 1. Este pacote vai para o repositório oficial e para o banco de produção. Antes de alterar a produção, peça o meu ok.
```

O Claude vai pedir a sua confirmação antes de alterar o banco, a Vercel ou o site no ar.

## Tenha em mãos
- Acesso ao Supabase oficial, à Vercel e ao GitHub.
- CPF e endereço que vão aparecer no site como dados do vendedor.
- Os e-mails dos 3 sócios para o painel admin.

## O que este pacote não faz
A cobrança continua desligada. Nenhum cliente será cobrado até você decidir ligar.
